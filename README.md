# JetWeatherForecast
JetWeatherForecast is a personal Android project built to practice and demonstrate hands‑on experience with modern Android development using Kotlin, Jetpack Compose, MVVM, Coroutines, Retrofit, Room, and Hilt.
The goal of this project is to showcase practical skills in building a complete, real‑world mobile application from scratch.

# TechStack
- Kotlin
- Jetpack Compose
- ViewModel + StateFlow
- Coroutines
- Retrofit (Weather API)
- Room (local caching)
- Hilt Dependency Injection
- Navigation Compose

# Overview
The app fetches weather data from an external API, caches it locally, and displays it through a fully declarative UI built with Jetpack Compose.
It includes loading/error states, navigation, dependency injection, and a clean separation of concerns following MVVM best practices.
